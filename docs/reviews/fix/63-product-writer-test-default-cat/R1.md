### [R1-1][Medium][CLAUDE.md:117（追加行）]（自己レビューで検出）
「`--order-by=random` の全体実行はネストしたスイート単位でシャッフルされるため先頭クラスになる確率は低い」という記述が**誤り**。`phpunit.xml.dist` の `<directory>` は全ファイルを1つのスイートにまとめ、`TestSuiteSorter` は各階層で子をシャッフルするが、実測（seed 987 の実行順が `Woo\Support` → `Woo\Writer` → `Adapters\ColorMe` → `Sync` … とディレクトリをまたいで混在）ではクラスは全体でフラットにシャッフルされる。先頭になる確率は約 1/60。CLAUDE.md は毎セッション読まれる必須ルールなので、seed 探索の工数判断を誤らせる。
判定: 修正（Medium。誤ったガイダンス）
**修正方針:** 「クラスは全体でフラットにシャッフルされ、特定クラスが先頭になるのは約 1/クラス数」に直す。
