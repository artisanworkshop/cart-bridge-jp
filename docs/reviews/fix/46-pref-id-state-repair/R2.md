## 新規指摘（R1 の修正で混入）

**修正:** `try/finally` で、実際に書き込めた側だけを監査メタに残す。テスト `test_a_partial_customer_write_still_records_the_side_that_was_written`（`update_user_metadata` フィルターで shipping だけを握りつぶす）を追加。
