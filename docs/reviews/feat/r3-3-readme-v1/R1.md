### [R1-1][High][readme.txt:52・94]（独立レビュー A-1）
「A real import or export moves a sample … use Tools > Sample data cleanup to remove it」が、エクスポートのサンプルにもクリーンアップを勧めていた。`SampleCleanup` は取込みで作った実体だけを消し、エクスポートで結んだ実体は紐づけを外すだけ、さらに最終処理で mapping と `ExportSampleSelector::clear()` を消す（SampleCleanup.php:236-244, 262-290）。Color Me Shop 側は何も消えないので、従うと次のエクスポートで Color Me Shop に重複を作る（docs/03 §10.2「E2-2 PR-A」の既知の制限）。配布する readme が本番の店舗に重複を作る操作へ案内していた。
**修正方針:** クリーンアップは取込みのサンプル用で Color Me Shop では何も消さないこと、エクスポートの間にクリーンアップすると次のエクスポートで重複することを、説明と FAQ に書く。→ **修正済み**

### [R1-2][Medium][readme.txt:102-116]（独立レビュー A-2）
