### [G1-1][Copilot][High][includes/Sync/Exporter.php:159]
`RateLimitExhaustedException`が`push_*()`から投げられた場合、汎用`Throwable`catchで
1件の異常として握り潰される。`Importer`は該当するASP APIコール（`fetch_page()`）がこの1件tryの
外側にあるため元々問題が起きないが、exportは`push_*()`がアイテムごとに呼ばれるため、レート制限に
達した以降の全アイテム（このページ・後続ページとも）が「1件ずつ失敗」として処理され、
`JobManager`の一時停止・再開（`RateLimitExhaustedException`専用catch。03 §3 ステートマシン）が
機能しなくなる。
判定: 修正（妥当。CLAUDE.mdアーキテクチャ原則5「レート制限遵守」に関わるHigh）
**対応:** `catch ( RateLimitExhaustedException $exception ) { throw $exception; }`を汎用
`Throwable`catchより先に追加し、`JobManager`まで伝播させる。テスト
`test_rate_limit_exhausted_exception_propagates_instead_of_being_swallowed`を追加。
コミット: 3a83bc6 / スレッド: https://github.com/artisanworkshop/cart-bridge-jp/pull/40#discussion_r4001588777
