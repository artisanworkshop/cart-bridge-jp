## 指摘（R1 の修正で入ったもの）
### [R2-1][Low][plugins/cart-bridge-jp-pro/tests/unit/Woo/Writer/CustomerWriterTest.php:test_protected_account_is_not_reported_as_linked]
`validate( $customer, $admin_id )` は mapping の経路で、修正前もこの経路には理由が付かなかった（R1-1 についてトートロジー）。
**対応:** `validate( $customer, null )`（メール一致の経路）も確かめる → 修正済み

### [R2-2][Low][.claude/rules/woocommerce-api.md]
R1-L6 の WP の挙動（SVG は `wp_get_image_mime()` が判定できず fileinfo で通る）がルールに無い。
**対応:** ルールに足した → 修正済み

### [R2-3][Low][SkuGuard::lookup_key() / docs/03 §10.9]
整形で変わる型番のバリエーションは、オプション値が今の商品と合わない古い受注だと SKU で救えなくなった（`order_line_variation_unmatched` の行。警告つき）。フィクスチャ・既存テストに整形で変わる型番は 0 件。
**対応:** docs/03 §10.9 の「受け入れたもの」に記録した
