## 指摘
### [G3-1][Codex P2][plugins/cart-bridge-jp/includes/Woo/Support/MediaImporter.php:136]
要旨: G1-1 の拡張子の絞り込みで `.svg` は閉じたが、`payload.jpg` のような URL は最初の `media_sideload_image()` が中身を画像と確かめずに添付を作りうるので、フォールバックの判定に届かない。最初の経路の成功も同じ判定で確かめるか、すべてを確かめる経路に通すこと
<!-- 判定は 修正 / 保留 / 対応不要 のいずれかで始める。対応不要のスレッドを Resolve するにはユーザー承認を得たうえで判定に 【承認済み】 と書き添える -->
判定: 修正（Low〜Medium 相当。WP は画像の拡張子なら `wp_get_image_mime()`、判定できなければ fileinfo で中身と種類を照らすので多くは弾かれるが、fileinfo が無いサーバーでは確かめない。G1-1 と続けて同じ箇所を指摘されたので、判定を 2 つの経路に分けない形にした）
対応: `media_sideload_image()` をやめ、取得は `download_url()` → 判定（WP の種類が `image/` で `wp_get_image_mime()` も画像）→ `media_handle_sideload()` の 1 つの経路（`sideload()`）だけにした。G1-1 の拡張子の絞り込み（`raster_extensions_only()`）は不要になったので外した。`media_sideload_image()` と同じく URL の名前と `_source_url` を残す。二重の取得（backlog F-5 の一部）も無くなった。テストに「画像の拡張子で中身が HTML」を足し、既存のテストで名前・`_source_url`・種類を確かめる
