## 指摘
### [G3-1][Codex][Medium][includes/Woo/Tools/SampleCleanup.php:342] 削除可否を可変の `_cbjp_platform` で判定している（P2）
A 作成 → B 採用 → B がリンク解除 → A のクリーンアップは `_cbjp_platform`（空）≠ A で unlink になり、A の mapping・サンプルだけリセットされてアカウントが残る。/ 判定: **修正**
**対応:** 作成元判定は不変のマーカーを正とし、別プラットフォームがリンク中（その受注が参照）でなければ削除。unlink 時はマーカーを残す（作成元が再リンクすれば削除できる）。テスト `test_creator_platform_can_delete_its_account_once_the_adopting_platform_unlinked_it`。/ スレッド: https://github.com/artisanworkshop/cart-bridge-jp/pull/34#discussion_r3983840554

### [G3-2][Codex][Medium][includes/Woo/Tools/SampleCleanup.php:451] 共有サムネイルのプレビュー過大計上（P2）
`MediaImporter` が同一 URL の画像をタームで共有するため、消えるタームが1つでも参照していれば削除対象に数えていた（実行は残す）。/ 判定: **修正**
**対応:** 参照する**全ての**タームが消える場合のみ削除対象にする（`terms_by_thumbnail()`）。テスト `test_shared_term_thumbnail_is_kept_while_another_term_still_uses_it`。/ スレッド: https://github.com/artisanworkshop/cart-bridge-jp/pull/34#discussion_r3983840557

### [G3-3][Codex][Medium][includes/Sync/VerificationReport.php:86] 通貨判定が現在の店舗設定に依存（P2）
USD で取り込んだ後に店舗通貨を JPY に変えると不一致が消え、換算していない数値が一致扱いになる。/ 判定: **修正**
**対応:** リンク済み受注に保存された通貨（`WC_Order::get_currency()`）を `LocalEntityLookup::summarize_orders()` で集め、それが `[JPY]` でない（混在含む）場合を不一致とする。テスト `test_currency_comes_from_the_imported_orders_not_the_current_store_setting`。/ スレッド: https://github.com/artisanworkshop/cart-bridge-jp/pull/34#discussion_r3983840560
