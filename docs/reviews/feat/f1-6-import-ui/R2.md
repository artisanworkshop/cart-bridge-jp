## 新規指摘

### [R2-1][Low][src/components/RunProgress.tsx:179-215]
R1-1の修正（`reportsAvailable`によるCSV UI非表示化）の副作用として、`isTerminal`かつ
`reportsAvailable=false`（＝実移行完了後）の場合、ツールバー`div`が空のまま
`margin-bottom: 1.5em`のスタイルだけ残り、見出しとジョブ一覧の間に不要な余白が生じていた。
**対応:** ツールバー`div`自体を`{ ( anyActive || reportsAvailable ) && ( ... ) }`で囲み、
表示すべき中身が無い場合はDOMごと出力しないよう修正済み。実機確認: 「Import results」で
ヘッダー直下にツールバーの空白が生まれず、直接「Categories / Completed」が続くことを確認。
新規Critical/Highではないため、このR2内で修正しループを継続しない。
