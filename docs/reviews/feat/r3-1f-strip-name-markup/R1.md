## 指摘

### [R1-1][Medium][includes/Woo/Support/HtmlText.php:visible_text]
`<br>` だけを空白にしていたので、ブロック要素（`<div>`・`<p>`・`<li>`・`<hr>`）の境目で語がくっつく（`<div>Cotton</div><div>Shirt</div>` → `CottonShirt`。ブラウザは改行して表示する）。テスト・文書にも無かった（独立レビュー A-1）。
**修正方針:** `BREAKING_TAGS`（`<br>` とブロック要素）の開始・終了タグを空白 1 つにし、テスト 5 件（ブロック・段落・リスト・`<hr>`・インライン要素はつなげたまま）を足す。リハーサルの期待値（DOM）もブロック要素の前後に空白を置く。

### [R1-2][Low → 修正済み][docs/03-design-decisions.md・docs/10-tasks.md・HtmlText.php の docblock]
「ブラウザと同じく `<textarea>` の中身は出ない」は誤り（ブラウザは表示する）。HTML API が中身を文字として返さない要素は `<xmp>`・`<iframe>`・`<noembed>`・`<noframes>` もある（独立レビュー A-3）。差分内の記述の誤りなので直した。
**修正方針:** 「HTML API が中身を文字のトークンとして返さない要素」と事実どおりに書き、`<textarea>`・`<xmp>`・`<plaintext>` がブラウザと違うことを明記。

### [R1-3][Low → 修正済み][docs/03-design-decisions.md §10.2]
「タグ・実体参照を含む名前は一度だけ更新」は範囲が狭い。`<` か `&` を含む名前は空白の連続・前後の空白・セミコロンの無い古い実体参照（`&copy2023` → `©2023`）でも変わり、更新は Woo の手直しを上書きする（独立レビュー A-4）。
**修正方針:** 文言を正確にし、changelog に書くことを R3-3 の項目に足す（R1-5 と合わせて）。

### [R1-4][Low → 修正済み][includes/Canonical/CanonicalProduct.php docblock]
表示される文字が無い名前は元の値（HTML）のまま Canonical に入るが、契約の docblock が触れていない（独立レビュー A-6）。
**修正方針:** 例外と「受け取る側は常に平文として扱う」を docblock に書く。

### [R1-5][Low → 修正済み][docs/10-tasks.md R3-3]
F1 を「対応済み（取込み）」で閉じたので、readme・FAQ に書く既知の限界（エクスポートの `<…>` が ColorMe で HTML になる、取込みでタグを除く）がどこにも追跡されていない（独立レビュー A-5）。
**修正方針:** R3-3 の項目に商品名の扱いと changelog の注意を足す。
