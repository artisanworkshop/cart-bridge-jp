## 指摘
### [R1-1][Medium][includes/Admin/RestController.php:513]
409 の文言が「Import／Export タブでキャンセル」と案内するが、両タブは接続済み（`c.connected`）のプラットフォームしか並べない（`src/tabs/ImportTab.tsx:128`・`ExportTab.tsx:289`）。
未接続・要再接続（`needs_reconnect`）のときボタン名は「Clear saved credentials」になり、まさにその状況で案内が行き止まりになる。
さらに要再接続の状態では、次のとおり切断が唯一の復旧手段になっている（サブエージェントが一時テストで実測）。
- `PUT /connections` は 409 `cbjp_save_conflict`
- `authorize-url` は 400 `cbjp_oauth_not_configured`

一方、Tools タブは全プラットフォームを並べ、未接続でも `ActiveRunNotice` が Cancel run を出す（`src/tabs/ToolsTab.tsx:675-681`）。
また、失敗して止まった run（`has_failed_job`）にも「A run is in progress」と出て、`ActiveRunNotice` の「stopped because a job failed」と表現が食い違う（R1-L5 をここで併せて直す）。
**修正方針:** 文言を「A run on this platform has not finished yet. Cancel it on the Tools tab (or the Import or Export tab) first, then try again.」にする（どの状態でも辿れる Tools タブを先に挙げ、止まった run にも合う中立な表現）。要再接続＋止まった run のテストを足す。docs/03・docs/10 の文言を合わせる。
