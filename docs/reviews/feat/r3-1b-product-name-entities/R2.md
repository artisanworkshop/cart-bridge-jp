## 新規指摘
### [R2-1][Low][docs/reviews/feat/r3-1b-product-name-entities/R1.md:R1-2]
R1-2 の「『更新時だけ符号化しない』退行でも通っていた」は誤り（生の名前は保存済みの値と違うので `name` が変更に入り、旧テストでも `wp_update_post()` → kses で落ちる）。旧テストが確かめていなかったのは「正しいコードで保存済みの名前が更新時の kses で変わらないこと」。テストの docblock の「何も確かめなくなる」も言い過ぎ。
**修正:** 対応済み（R1.md の根拠を訂正し、根拠の変異を `<` `>` の非符号化に差し替え。docblock を「更新時の kses での安定性を確かめなくなる」に）。

**修正:** 対応済み（`wp_unslash( sanitize_term_field( … ) )` に）。
