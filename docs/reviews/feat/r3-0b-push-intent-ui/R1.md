### [R1-1][Medium][src/components/PushIntentsPanel.tsx / src/tabs/ExportTab.tsx]（独立レビュー指摘）
一覧の GET はマウント時（＝`platform` 変更時）の1回だけで、再取得の経路が無かった。同じ Export
タブを開いたまま実 export を実行し、新たに ambiguous な push intent（`PUSH_OUTCOME_UNCONFIRMED`）が
記録されても、パネルはタブ切替かリロードをするまで表示されない。D21-B の主眼（export でブロック
された実体を店舗が見つけて解除する）に直接効く。
**修正方針:** `runInProgress`（dry-run export／実 export の実行中フラグ）が true→false に変わった
ときに `fetchIntents()` を呼ぶ（`wasInProgressRef` で前回値を追跡）。stale 応答の破棄は既存の
`generationRef` に任せる。
