## 新規指摘（R1修正で混入したもの）

### [R2-1][Medium][includes/Adapters/ColorMe/Transform/CustomerTransformer.php:join_address1()]
`city`+`address_1`の区切り無し連結（R1-1の修正）は日本語住所では正しいが、海外住所
（`pref_id=48`）に同じ規則を適用すると単語がくっつく（例:
`'Los Angeles'+'123 Main St'`→`'Los Angeles123 Main St'`）。独立サブエージェントの検証で
`php -r`実測により確認。
**対応:** `join_address1()`に`$is_overseas`（`48 === $pref_id`）を渡し、海外のみ半角スペースを
挟むよう修正。日本国内・往復顧客の挙動は不変。テスト追加、commit 1d58e76。

### [R2-2][Low][includes/Adapters/ColorMe/Transform/CustomerTransformer.php:normalize_tel()]
`'/^[0-9\-]+$/'`の`$`はPCRE仕様上、末尾改行の直前にもマッチするため、`billing_phone`に
混入した末尾`\n`を見逃し確実に422になる値をそのまま送りかねない（`preg_match`実測で確認）。
**対応:** 終端アンカーを`\z`に変更。テスト追加、commit 1d58e76。
