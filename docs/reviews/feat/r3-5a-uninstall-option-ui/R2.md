## 指摘
### [R2-1][Low][plugins/cart-bridge-jp/readme.txt:122]
「on a multisite network only the main site's setting and data are used」が条件なしの言い切りで、WP-CLI の `wp plugin uninstall --url=<サブサイト>` ではサブサイトの設定とデータが使われる。「data are used」も「消すのはメインサイトのデータだけ」と読み取りにくい。
**修正方針:** ネットワーク管理画面からの削除に限って「reads only the main site's setting and deletes only the main site's data」とする。docs/03 にも WP-CLI の `--url` を併記。→ **Low → 修正済み（1636d70）**

### [R2-2][Low][plugins/cart-bridge-jp/includes/Core/Uninstaller.php:54・docs/03-design-decisions.md §7]
R1-1 の修正で書いた「取り消せるのは期限の来ていないもの」「停止中に期限の来たものはすでに失敗している」は、停止中に AS のキューが動いた場合にしか正しくない。`cancel_actions_by_group()` は期限によらず pending を全部取り消す（期限が来ていてもキューが動かず残ったものも取り消す。実害は無く、望ましい結果）。
**修正方針:** 「pending のものを期限によらず取り消す。停止中にキューが動いていれば、期限の来たものはすでに失敗している」に直す。→ **Low → 修正済み（1636d70）**
