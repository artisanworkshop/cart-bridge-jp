## 新規指摘

### [R2-1][Medium][includes/Sync/Exporter.php:492-506（`$did_push`の`else`節）]
R1-1の修正で`else`節（`$did_push`がfalse）にも`mark_ambiguous()`の経路ができたが、直後の
クォータ解放（`if ($consumed_quota_slot) { ++$remaining; }`）が無条件のままだった。R1-2で
`catch (Throwable)`側だけを直した際の横展開漏れ。`PushResult('', OPERATION_CREATED)`（R1-1が
扱う契約違反そのもの）を返すアイテムは印を残すのに枠だけ解放され、同じページの後続アイテムが
同じ枠を二重に使いうる（原則7）。
**判定: 修正**（R2着手前に自己レビューで検出・修正済み）。`catch (Throwable)`と同じ
`$intent_kept_ambiguous`ガードを`else`節にも適用。境界テストを追加
（`test_a_push_result_kept_ambiguous_does_not_free_up_its_quota_slot_within_the_same_page`）。
修正を戻すと当該テストが失敗することを確認済み。
