## 指摘

### [R1-1][Medium][languages/cart-bridge-jp-ja.po（"No WooCommerce payment methods are available. …"）]
「WooCommerce > Settings > Payments」を「設定 > 支払い」と訳していたが、WooCommerce の設定のタブ名は `_x( 'Payments', 'Settings tab label' )` の訳「決済」（「支払い」は文脈なしの msgid の訳で、トップレベルのメニュー）。案内どおりに探すとタブが見つからない（独立レビュー S1）。
**修正方針:** 「WooCommerce > 設定 > 決済」にし、用語集（`docs/03` §6）に足す。→ 修正済み

### [R1-2][Medium][languages/cart-bridge-jp-ja.po（Regular price を含む 7 文字列）]
WooCommerce の商品の項目名「Regular price」の訳は「標準価格」、「Simple product」は「基本的な商品」だが、PO は「通常価格」「シンプルな商品」と訳していた。対処の文言が指す項目名が画面と食い違う（独立レビュー T1）。
**修正方針:** 「標準価格」「基本的な商品」に置き換え、用語集に足す。→ 修正済み

### [R1-3][Medium（成果物の記述の事実誤り）][bin/i18n.sh:33-35,110、docs/reviews/feat/r3-2-i18n/dev-cycle.md]
`bin/i18n.sh` のコメントと状態ファイルが「wp-env run は呼ぶたびにコンテナを作る」「CI ではコンテナからリポジトリへ書けるとは限らない」と書いていたが、wp-env 10 の `run` は起動中のコンテナへホストの uid で `docker compose exec` する（`node_modules/@wordpress/env/lib/runtime/docker/index.js`）。あわせて、警告を受ける `mktemp` の一時ファイルを消しておらず、コンテナの `/tmp` に溜まっていた（独立レビュー L2。Low として出たが、R3-0k の R1 と同じく成果物の記述の事実誤りは Medium として扱う）。
**修正方針:** コメントを実際の動きに直し、コンテナの中の `bash -c` に `trap 'rm -f "$err"' EXIT` を足し、check の POT も比べ終わったら消す。状態ファイルの記述も訂正する。→ 修正済み（check の前後でコンテナの `/tmp` が増えないことを実測。前の実行で残った空の一時ファイル 5 個は名前を指定して消した）

### [R1-4][Low → 修正済み（画面のエラー表示）][includes/Admin/RestController.php:get_authorize_url]
本 PR で足した「Save the Client ID and Client Secret first, then connect.」は、要再接続（保存した値を復号できない）でも返る（`TokenStore::get()` が null → `settings()` が `[]` → `authorize_url()` が例外）。この状態では資格情報の保存も失敗するので、案内どおりにすると行き止まりになる（CLAUDE.md の `needs_reconnect` の項。挙動は以前から英語の例外メッセージで同じ。独立レビュー L1）。cbj-dev-cycle の例外（画面のエラー表示に関わる Low は数行で直せるなら R1 で直す）として修正した。
**修正方針:** `needs_reconnect()` なら「保存した認証情報を消去」へ案内する文言を返す（テスト `test_get_authorize_url_points_to_clearing_credentials_that_cannot_be_read`。分岐を `false` にする変異で CAUGHT）。→ 修正済み

### [R1-5][Low → 修正済み（訳の手直し）][languages/cart-bridge-jp-ja.po]
訳は本 PR の成果物そのもので、backlog に送ると次の再翻訳（R5-1）まで直らないため、数語の手直しは R1 で直した（独立レビュー T2・T3・T4・T6）:
