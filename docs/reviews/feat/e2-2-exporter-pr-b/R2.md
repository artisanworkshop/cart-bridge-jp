## 新規指摘（R1修正差分で混入。いずれもMedium。その場で修正）

### [R2-1][Medium][includes/Woo/Reader/CouponReader.php:43-48]
`orderby => 'date', order => 'DESC'`にタイブレークが無く、`post_date`が同一秒のクーポン群
（自プラグインの一括作成等）でページ跨ぎの順序がMySQL実装依存になり重複/欠落しうる。
**修正:** `orderby`を`['date' => 'DESC', 'ID' => 'DESC']`に変更。回帰テスト
（`test_query_orders_deterministically_when_dates_are_identical`）追加。

### [R2-2][Medium][includes/Woo/Reader/OrderReader.php:457-467]
新設`fee_total()`が`line_item_amounts()`/`totals()`と非対称に金額の符号・数値妥当性を検証して
おらず、負のFee明細（値引きプラグイン等が作りうる）がそのまま`payment.fee`に載る。
**修正:** 共有ヘルパー`validated_amount()`を新設し`fee_total()`と送料合算（`shipping()`）の
両方に適用。回帰テスト（`test_negative_fee_line_item_does_not_reduce_the_payment_fee_total`）追加。
