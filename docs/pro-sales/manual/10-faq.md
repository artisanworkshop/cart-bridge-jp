# 困ったときは

## カラーミーショップに接続できない

- アプリの承認は、ショップのオーナーのアカウントで行ってください。副管理者のアカウントでは承認できません。
- アプリのリダイレクト URI が、「接続」タブのコールバック URL と同じか確かめてください（末尾の `/` まで同じである必要があります）。
- ローカルの開発環境など、インターネットからサイトが見えないときは、「ローカルで接続できませんか？」から手動で接続してください（「インストールと接続」の章）。

## 「この接続には、一部の種類の記録に必要な権限がありません」と出る

無料版で接続した後に Pro を有効にしたときに出ます。「カラーミーショップに接続し直す」をクリックし、もう一度アプリを承認してください。

## プレビューや取り込みが「一時停止中（利用制限）」のまま

カラーミーショップの API の利用制限に達したときに、一時的に止まります。少し待つと自動で再開します。

## 警告の意味が分からない

プレビューのレポート（CSV）に、警告ごとの原因と、できるときは直し方が書かれています。`severity` が `blocking` の警告が、データを止めている警告です。レポートに出ないものは「ログ」タブを確かめてください。

## 顧客・注文・クーポンを取り込めない

ライセンスキーを有効化するまで、顧客・注文・クーポンはプレビューだけです。「Cart Bridge JP Pro」の「ライセンス」タブでキーを有効化してください。カラーミーショップの非会員の購入者は、顧客としては取り込みません（注文には購入者の名前と住所が残ります）。

## 取り込んだ顧客がログインできない

カラーミーショップのパスワードは移せません。新しいストアに切り替えた後に、パスワード設定メールを送ってください。顧客は、パスワードを忘れた場合のページからも、自分でパスワードを設定できます。

## カラーミーショップと WooCommerce を同期したい

同期には対応していません。一方向の移行のためのプラグインです。

## BASE や MakeShop から移行したい

現在はカラーミーショップだけに対応しています。BASE・MakeShop は、今後のバージョンで対応する予定です。

## ライセンスの期限が切れた

有効化済みのサイトでは、そのまま使い続けられます。新しいサイトでの有効化と、アップデートの受け取りはできません。新しい移行の案件では、改めてご購入ください。

## ステージングのデータベースを本番に移した（または逆）

- 移した先のサイトで紐づけが失われたときは、「ツール」タブの「紐づけを再構築」で、取り込んだデータの紐づけを復元できます。
- データベースを複製したサイトで、ライセンスを「無効化」しないでください。複製元のサイトもライセンスから外れます（「ライセンスを有効化する」の章）。

## お問い合わせ

ライセンスの期間（初回の有効化から 3 か月）の間は、メールでのサポートを受けられます。販売サイト（https://wc.artws.info/）からお問い合わせください。
