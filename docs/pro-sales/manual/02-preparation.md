# 準備

## 動作環境

| 項目 | 条件 |
| --- | --- |
| WordPress | 6.9 以上 |
| PHP | 8.2 以上。保存する認証情報の暗号化に PHP の sodium 拡張を使います（多くの環境に含まれています） |
| WooCommerce | 10.0 以上。HPOS（高性能な注文の保存）に対応しています |
| Cart Bridge JP（無料版） | WordPress.org から最新版をインストールします |
| カラーミーショップ | ショップと、デベロッパーセンターに登録したご自身のアプリ |

受注のエクスポート（ベータ版）と商品画像のアップロード（ベータ版）は、カラーミーショップのプレミアムプランのショップでだけ使えます。

## カラーミーショップで用意するもの

1. **ショップのオーナーのアカウント**: アプリの承認は、ショップのオーナーのアカウントで行います。副管理者のアカウントでは承認できません。
2. **デベロッパーセンターのアプリ**: カラーミーショップのデベロッパーセンターで、移行に使うアプリを登録します。アプリのリダイレクト URI には、WordPress の接続の画面に表示されるコールバック URL を登録します（「インストールと接続」の章）。登録すると、クライアント ID とクライアントシークレットが発行されます。

このプラグインは、ご自身で登録したアプリでカラーミーショップの API に接続します。販売元のサーバーを経由することはありません。

## 移行の前に

- **バックアップを取ってください。** 取り込みは WooCommerce に商品・顧客・注文を書き込みます。取り込んだデータを一括で取り消す機能はありません。
- **できればステージング（検証用）のサイトで先に試してください。** ライセンスキーはサイトの数に制限なく有効化できるので、ステージングと本番の両方で使えます。
- **メールの送信の準備をしてください。** パスワード設定メールを一斉に送るときは、SMTP のプラグインやメール配信サービスを使うことをおすすめします。レンタルサーバーの多くは、1 時間に送れるメールの数を制限しています。
- **WooCommerce の配送地域と配送方法を作っておいてください。** 取り込んだ注文の配送方法を、WooCommerce の配送方法に対応させるときに使います（「マッピング」の章）。
