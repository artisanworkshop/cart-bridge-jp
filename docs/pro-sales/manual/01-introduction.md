# はじめに

## このマニュアルについて

このマニュアルは、カラーミーショップから WooCommerce へストアを移す方に向けて、次の 2 つのプラグインの使い方を説明します。

- **Cart Bridge JP – Migrate for WooCommerce**（以下「無料版」）: WordPress.org で配布している無料のプラグイン。商品まわりのデータを移します。
- **Cart Bridge JP Pro**（以下「Pro」）: 無料版に機能を足すアドオン。顧客・受注・クーポンを移し、取り込んだ顧客へパスワード設定の案内を送ります。

画面は、無料版 1.0.1・Pro 1.0.0 の日本語の管理画面です。画面に写っている店舗・顧客・注文のデータは、説明のための架空のものです。

## 無料版と Pro の分担

Pro は単体では動きません。無料版を入れたサイトに、Pro を追加して使います。

| データ | 取り込み（カラーミーショップ → WooCommerce） | エクスポート（WooCommerce → カラーミーショップ） | 必要なもの |
| --- | --- | --- | --- |
| カテゴリー・グループ | ○（グループは商品タグになります） | —（※1） | 無料版 |
| 商品（オプション・画像を含む） | ○ | ○（画像のアップロードはベータ版。※2） | 無料版 |
| 在庫 | ○ | ○ | 無料版 |
| 顧客 | ○ | ○ | Pro |
| 受注（注文） | ○ | ベータ版（※2） | Pro |
| クーポン | ○ | —（※3） | Pro |
| 取り込んだ顧客へのパスワード設定メール | — | — | Pro |

- ※1 カラーミーショップの API ではカテゴリーを作れないため、WooCommerce のカテゴリーをカラーミーショップの既存のカテゴリーに対応させて送ります。
- ※2 カラーミーショップのプレミアムプランでだけ使える機能です。プレミアムプランの実店舗ではまだ確かめていないため、ベータ版として提供し、既定ではオフです。
- ※3 カラーミーショップの API では、クーポンは読み取ることしかできません。

## 移行の流れ

1. **準備**: 動作環境を確かめ、カラーミーショップのデベロッパーセンターにアプリを登録します（「準備」の章）。
2. **インストール**: 無料版と Pro をインストールします。購入前は、販売サイトで 0 円の Pro を入手します（「インストールと接続」の章）。
3. **接続**: WordPress からカラーミーショップに接続します。
4. **マッピング**: 決済方法・配送方法・注文ステータスなどを、WooCommerce のどれに当てるか決めます（「マッピング」の章）。
5. **プレビュー（dry-run）**: 何も書き込まずに、全件の変換結果と警告を確かめます。ライセンスキーが無くても実行できます（「プレビューで確かめる」の章）。
6. **ライセンスの購入と有効化**: 結果に問題が無ければライセンスキーを購入し、Pro の画面で有効化します（「ライセンスを有効化する」の章）。
7. **取り込み**: 実際に取り込み、検証レポートで件数と金額を確かめます（「取り込む」の章）。
8. **パスワード設定メール**: 新しいストアに切り替えた後、取り込んだ顧客にパスワードを設定する案内を送ります（「パスワード設定メールを送る」の章）。

## 一方向の移行のためのプラグインです

Cart Bridge JP は、カラーミーショップから WooCommerce へ、または WooCommerce からカラーミーショップへの**一方向の移行**のためのプラグインです。定期的に差分を同期したり、在庫を双方向に同期したりする使い方には対応していません。

誤って同じデータを行き来させたときに値を壊さないよう、カラーミーショップから取り込んだデータはカラーミーショップへエクスポートされず、エクスポートでカラーミーショップに作ったデータは後の取り込みで上書きされません。

## 画面の言葉

| 言葉 | 意味 |
| --- | --- |
| プラットフォーム | 移行元・移行先のショップのサービス（このマニュアルではカラーミーショップ） |
| プレビュー（dry-run） | 何も書き込まずに、移行の結果を確かめる実行 |
| インポート（取り込み） | カラーミーショップのデータを WooCommerce に書き込む実行 |
| エクスポート | WooCommerce のデータをカラーミーショップに書き込む実行 |
| マッピング | カラーミーショップの値（決済方法など）を WooCommerce の値に対応させる設定 |
| 紐づけ | 移行したデータと、元のデータとの対応の記録。2 回目以降の取り込みで、同じデータを新しく作らずに更新するために使います |
