無料プラグイン Cart Bridge JP のアドオン

顧客・受注・クーポンも、WooCommerce へ。

Cart Bridge JP Pro は、カラーミーショップと WooCommerce の間でデータを移す無料プラグイン「Cart Bridge JP」に、顧客・受注・クーポンの移行を加えるアドオンです。商品は無料版で、会員と注文の履歴は Pro で移せます。

ライセンスキーが無くても、全件の dry-run（何も書き込まないプレビュー）を実行できます。ご自身のショップのデータで結果を確かめてからご購入ください。

無料版と Pro の分担

Pro は単体では動きません。WordPress.org で配布している無料版 Cart Bridge JP に機能を足すアドオンです。商品まわりは無料版が、顧客・受注・クーポンは Pro が移します。

表の「取り込み」はカラーミーショップから WooCommerce へ、「エクスポート」は WooCommerce からカラーミーショップへの移行です。

※1 カラーミーショップの API ではカテゴリを作れないため、WooCommerce のカテゴリをカラーミーショップの既存のカテゴリに対応付けて送ります。
※2 カラーミーショップのプレミアムプランでだけ使える API を使います。プレミアムプランの実店舗ではまだ確かめていないため Beta として提供し、既定ではオフです。
※3 カラーミーショップの API では、クーポンは読み取ることしかできません。

Pro でできること

顧客を移す

氏名・メールアドレス・住所・電話番号・会社名などを、WooCommerce の顧客として取り込みます。WooCommerce に項目の無いフリガナ・生年月日・メールマガジンの購読の有無も、顧客のデータとして残します。同じメールアドレスのアカウントがすでにあれば、新しく作らずに結び付けます。

受注を移す

注文番号・注文日時・明細・金額・決済方法・配送先・ステータスを、WooCommerce の注文として取り込み、購入した顧客と結び付けます。HPOS（高性能な注文の保存）に対応しています。取り込んだ注文で在庫が減ったり、注文のメールが送られたりはしません。

クーポンを移す

コード・割引の種類と額・最低購入金額・有効期限・利用回数の上限・送料無料の設定を、WooCommerce のクーポンとして取り込みます。WooCommerce で表せない条件を持つクーポンは、条件を落として作ることはせず、警告を付けて取り込みを見送ります。

決済・配送・ステータスを対応付ける

カラーミーショップの決済方法・配送方法・注文ステータスを、WooCommerce のどれに当てるかを設定画面で選べます。対応付けた内容で受注を取り込みます。

パスワード設定メールを送る

取り込んだ顧客へ、新しいストアでパスワードを設定するための案内を一斉に送れます。管理者宛てのテスト送信で文面を確かめてから、少しずつ送ります。止めても続きから再開でき、すでにパスワードを設定し直した顧客には送りません。

移行の前後に確かめる

dry-run の警告レポート（CSV）に、顧客・受注・クーポンの警告の原因と直し方が並びます。取り込みの後は、検証レポートで件数と受注の金額をカラーミーショップと突き合わせられます。

購入の前に、全件を dry-run で確かめられます

ライセンスキーを有効化していない Pro でも、顧客・受注・クーポンの dry-run を件数の制限なく実行できます。

  1. 0 円の「Cart Bridge JP Pro」を注文して、プラグインをダウンロードします。
  2. 無料版 Cart Bridge JP と Pro をインストールし、カラーミーショップに接続して dry-run を実行します。
  3. 警告レポート（CSV）で、全件の変換結果と警告を確かめます。
  4. 問題が無ければライセンスキーを購入し、Pro の設定画面で有効化します。プラグインを入れ直す必要はありません。

キーを有効化するまでは、実際の取り込み・エクスポートと、パスワード設定メールの一斉送信はできません。

購入後の返金には対応していません。必ず dry-run の結果を確かめてからご購入ください。

ライセンス

  • 1 つのライセンスキーを、本番・ステージング・検証用など、サイトの数に制限なく有効化できます。
  • 初回の有効化から 3 か月間、アップデートとメールでのサポートをご利用いただけます。
  • 期限が過ぎても、有効化済みのサイトではそのまま使い続けられます。新しいサイトでの有効化とアップデートの受け取りはできなくなるため、新しい移行の案件では改めてご購入ください。
  • 定期的な差分の同期や在庫の双方向の同期など、継続的な同期には対応していません。一度きりの移行のためのアドオンです。

よくある質問

無料版だけで移行できますか？

商品・カテゴリ・グループ・在庫は、無料版だけで移せます。顧客・受注・クーポンを移すときに Pro が必要です。

ライセンスキーが無いと、何ができますか？

顧客・受注・クーポンの dry-run（件数の制限なし）と警告レポートの確認、パスワード設定メールの送り先の確認とテスト送信ができます。実際の取り込み・エクスポート、メールの一斉送信、アップデートの受け取りは、キーを有効化した後に使えます。

取り込んだ顧客は、新しいストアにログインできますか？

カラーミーショップのパスワードは移せないため、取り込みでは顧客のアカウントをランダムなパスワードで作ります。新しいストアに切り替えた後、Pro のパスワード設定メールで、パスワードを設定するためのリンクを送ってください。リンクの有効期限は 24 時間で、期限が切れたときのためにパスワードの再設定のページも案内します。

移行の途中で、顧客にメールが届きますか？

届きません。顧客や注文を取り込むときに、アカウント作成や注文のメールは送りません。顧客へのメールは、管理者がパスワード設定メールの送信を始めたときだけ送られます。

無料版で接続済みです。Pro を入れた後に必要なことはありますか？

無料版は、商品の読み書きの権限だけを求めてカラーミーショップに接続します。Pro を有効にすると顧客・受注・クーポンの権限も必要になるため、接続の画面の案内に従ってカラーミーショップに接続し直してください。

受注をカラーミーショップへ送れますか？

プレミアムプランのショップでは、Beta として送れます（既定はオフです）。カラーミーショップに受注を作る操作で、プレミアムプランの実店舗ではまだ確かめていないため、テスト用のショップで試してからお使いください。

カラーミーショップと WooCommerce を同期できますか？

できません。カラーミーショップから WooCommerce へ、または WooCommerce からカラーミーショップへの、一方向の移行のためのプラグインです。同じデータを行き来させる使い方には対応していません。

BASE や MakeShop には対応していますか？

現在はカラーミーショップだけに対応しています。BASE・MakeShop は、今後のバージョンで対応する予定です。
